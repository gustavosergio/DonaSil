# Fontes da loja

Arquivos oficiais das famílias Playfair Display e Poppins, distribuídos sob SIL Open Font License. Licenças completas nos arquivos `*-OFL.txt` desta pasta.

Fontes obtidas de https://github.com/google/fonts/tree/main/ofl/playfairdisplay e https://github.com/google/fonts/tree/main/ofl/poppins em 27/10/2026.

Usamos `next/font/local` para que a compilação não dependa de consultas ao Google Fonts. As famílias, estilos e pesos utilizados pela loja foram preservados.
